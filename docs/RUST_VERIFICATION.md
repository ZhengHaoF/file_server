## 本地执行记录

2026-10-12，Linux x64隔离环境；Rust 1.99、Node 22、Flutter 3.47.7。只访问专用临时共享目录，没有对真实NAS数据操作。

- **前端**：管理端65项、Web端11项测试通过，两个生产构建通过；生产管理端未使用mock。
- **Flutter**：`flutter analyze --no-fatal-infos --no-pub`无问题，`flutter test --no-pub`全套50项通过。此结果不等于原生应用实机验收。
- **旧Node参考实现**：lint、格式、typecheck、62项测试通过；保留用于完整旧版本回退，不作为新客户端的可替换后端。
- **Rust检查**：`npm run check:rust`中fmt检查、Clippy全target且warnings作为错误均通过，26个单元测试和18个真实TCP集成测试通过；媒体工具已安装，实际运行生成用例，不以缺少工具跳过代替通过。新增无效TLS测试确认HTTP端口不监听、数据库也不创建。
- **独立黑盒**：release可执行文件运行`npm run test:rust:smoke`15组通过，包括真实上传冲突、Range、媒体生成、64MP源图限额、伪装HLS外部请求拦截、预置缓存链接不泄漏凭据、候选root复用启动规则、SQLite持久化和supervise真实重启。
- **启动隔离**：release运行`npm run test:rust:security`7组通过，覆盖日志/数据库链接、TLS私钥共享路径、缓存别名拒绝不改共享权限、缺失静态目录祖先链接、私有数据根边界、无效TLS拒绝启动且监督者退出78。
- **独立审计**：两轮共8项已复现缺陷均修复，并由原始复现程序独立复核。缓存命中链接被移除并重建，文件身份不能读出私有长期凭据；不可启动的root候选在保存前返回400。未声称覆盖所有安全风险，Windows末级打开不跟随链接仅通过前置reparse检查，未经Windows实机复核。
- **浏览器补验**：手机抽屉打开/关闭、登出及当前会话撤销实际返回登录页；新配置保存使另一个页面的WebSocket日志条数从3增加到4，验证真实推送而非仅连接指示；CSV与JSON导出均触发真实下载。浏览器未发现pageerror。
- **分发产物**：最终release归档`dist/file-serve-rust-linux-x64.tar.gz`已生成，使用分发目录内的二进制再次执行15组黑盒和7组启动安全测试，均通过。媒体工具仍由目标机安装，不误称归档含FFmpeg/libvips。
- **演示预览**：另外构建隔离的浏览器内演示并明确标注示例数据，不连接真实后端或NAS；生产联调结果来自另一套真实Rust服务。演示产物不进入源码提交与安装包。
- **截图与下载**：本地`qa-artifacts/`保存桌面六页、浅/深概览、手机六页、文件预览以及配置/日志导出。该目录不提交、不打包；下载中的临时路径不是用户真实配置。
