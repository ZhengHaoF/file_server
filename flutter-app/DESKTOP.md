# Z-Files 桌面客户端

Windows、macOS 和 Linux 使用独立桌面文件浏览布局。手机端仍使用原有列表、网格和触屏操作，不根据窗口宽度将手机误切换成桌面交互。

## 浏览与操作

- 单击选择，双击打开；Ctrl 单击切换选择，Shift 单击范围选择。
- 文件区域获得焦点后，方向键移动，Enter 打开，F2 重命名，Delete 进入确认，Escape 清空选择。
- Ctrl+A 选择当前筛选结果；Alt+Left / Alt+Right 浏览历史；F5 刷新。
- 搜索仅作用于当前已加载目录，不是全服务器搜索。输入框和弹窗不受文件区域快捷键干扰。
- 右键使用指针位置弹出菜单，支持多文件加入下载队列；批量删除未开放。
- 名称、大小和修改时间列头可排序；网格按可用宽度自动调整列数。
- 侧栏在小窗口折叠为图标栏，窄列表隐藏次要列，详情栏仅在较宽窗口出现。
- 传输状态持续显示任务数量，点击进入现有上传/下载管理页。
- 外观支持跟随系统、浅色和深色；设置页和传输页限制最大内容宽度。

## 结构与安全边界

`DesktopFileBrowser` 只负责布局、搜索、排序、选择和交互；`HomePage` 继续负责 API、认证、预览、传输及危险操作确认。选择按文件路径绑定，排序后不会误操作原索引对应的其他文件；过滤或切换目录会清理不可见选择。

目录请求使用取消令牌和递增版本标记。换目录、刷新和卸载时取消旧请求，过期响应不会覆盖新目录；刷新失败保留当前目录上次成功数据并提示过期，目录切换不会混入旧目录数据。

本次没有改变后端权限、递归删除策略，也没有实现目录上传、断点续传或全盘搜索。桌面复制链接沿用现有只读访问票据机制，接收者应按现有访问策略使用。

## 音频与平台

音频改为使用已有 `media_kit` 播放体系，复用音视频原生库，不再依赖缺少 Windows 实现的 `just_audio`。媒体加载和播放错误提供提示与重试；音频输出、格式覆盖及系统设备变化仍需实机验收。

拍照上传仅在 Android/iOS 显示；桌面使用文件选择与拖入上传。Windows 原生标题改为 Z-Files，保留系统窗口框架及既有 DPI 配置。

## 验证

运行 `flutter analyze --no-fatal-infos` 和 `flutter test`。CI 新增 Windows release 构建并上传完整 Release 目录，下载后应解压全部文件，不能只取 exe。

交互测试覆盖选择、排序、多选、键盘编辑隔离、右键取消、目录切换、错误状态和大目录懒渲染。浏览器渲染检查可以辅助观察 Flutter 布局，但不等同于 Windows 原生运行验收。

发布前仍应在 Windows 10/11 检查 100%～200% 缩放、分屏、多显示器、音频、文件选择、Explorer 拖入和真实 NAS 网络。本轮未加入托盘驻留、窗口位置持久化或关闭活动任务保护，现有关闭窗口退出策略保持不变。
